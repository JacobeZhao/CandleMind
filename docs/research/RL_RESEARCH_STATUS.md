# 强化学习研究状态

## 当前定位

历史基线曾记录为 `SAR+ADX V3 paper trading`，该名称仅用于研究状态追踪，
不代表当前线上执行策略或事实业绩。

RL 尚未接入在线推理、策略启动或交易所下单链路。

CandleMind 保留基于 EMA 特征的强化学习趋势跟踪研究基础设施，用于离线特征研究、
数据发布、生命周期管理和历史实验复现。核心兼容模块位于 `backend/app/rl/`，相关
发布与只读验证逻辑位于 `backend/app/services/ema_data_release.py` 和
`backend/app/services/ema_release_verifier.py`。

这些模块属于受测试保护的数据与研究契约，不应因当前运行策略不同而删除或随意
迁移。

## 运行边界

当前公开策略页提供 CandleMind 趋势策略、SAR 马丁和 SAR 反马丁的配置入口，
保存后的配置由交易所执行运行时使用。系统没有在策略启动或订单决策路径中加载
PPO 或其他强化学习模型，因此“强化学习驱动当前策略”不属于项目现状。

公开产品不提供回测页面或 `/api/backtest/*` 接口。内部 evaluation/backtest 模块
仍用于离线研究、回归验证和历史实验复现，但不构成在线交易能力或公开 API 契约。

README 不展示人工模拟的收益或回撤数据。任何策略表现声明都必须来自可复现的
真实回测或运行账本；冻结研究文档才是当前实验结论的依据。

## 接入门槛

未来接入 RL 决策前，至少需要完成：

1. 固定可复现的数据清单、特征版本、标签和训练配置。
2. 使用严格的时间切分、走样本外评估和包含成本的压力测试。
3. 验证奖励函数不会鼓励过度交易、风险放大或利用未来数据。
4. 与确定性策略基线进行相同数据和成本口径的独立对照。
5. 先通过离线回放和 testnet 验收，再评估在线运行时集成。
6. 保留人工停机、仓位上限、最大回撤和异常数据保护。

任何接入都必须单独评审，不得绕过现有交易安全边界。
