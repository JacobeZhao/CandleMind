# 强化学习研究状态

## 当前定位

CandleMind 保留基于 EMA 特征的强化学习趋势跟踪研究基础设施，用于离线特征研究、
数据发布、生命周期管理和历史实验复现。核心兼容模块位于 `backend/app/rl/`，相关
发布与只读验证逻辑位于 `backend/app/services/ema_data_release.py` 和
`backend/app/services/ema_release_verifier.py`。

这些模块属于受测试保护的数据与研究契约，不应因当前运行策略不同而删除或随意
迁移。

## 运行边界

当前在线决策链路是 **SAR+ADX V3 paper trading**。系统没有在策略启动、回测或
订单决策路径中加载 PPO 或其他强化学习模型，RL 尚未接入在线推理，也不向交易所
发送真实订单。因此，“强化学习驱动当前策略”不属于项目现状。

README 不展示人工模拟的收益或回撤数据。任何策略表现声明都必须来自可复现的
真实回测或运行账本；冻结研究文档才是当前实验结论的依据。

## 接入门槛

未来接入 RL 决策前，至少需要完成：

1. 固定可复现的数据清单、特征版本、标签和训练配置。
2. 使用严格的时间切分、走样本外评估和包含成本的压力测试。
3. 验证奖励函数不会鼓励过度交易、风险放大或利用未来数据。
4. 与 SAR+ADX 基线进行相同数据和成本口径的独立对照。
5. 先通过离线回放和 testnet 验收，再评估 paper runtime 集成。
6. 保留人工停机、仓位上限、最大回撤和异常数据保护。

任何接入都必须单独评审，不得绕过当前 paper-only 安全边界。
