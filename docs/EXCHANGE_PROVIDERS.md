# 交易所与市场支持

## 当前范围

设置页提供全局市场选择器，选择结果持久化在后端设置中，并在刷新页面或切换目录后继续生效。稳定的 Provider ID 如下：

| 市场 | Provider ID | 状态 |
| --- | --- | --- |
| Binance | `binance` | 已接入 |
| OKX | `okx` | 规划中 |
| Bybit | `bybit` | 规划中 |
| Gate.io | `gateio` | 规划中 |
| A 股 | `a_share` | 规划中 |

只有 Binance 已实现行情、账户、订单、策略执行和 AI 行情分析。其他选项仅用于建立稳定的产品与配置契约，不代表已接入对应 API。

## 页面行为

选择未接入市场后，概览、行情和订单页显示“未连接 / 未来会接入，敬请期待”。页面同时隐藏 Binance 测试网/真实网切换，并禁用交易对、刷新、策略启动和 AI 行情分析入口。前端不会继续读取 Binance 业务接口；后端相关接口也会返回结构化的 `exchange_provider_unavailable` 错误。

## 切换安全

改变 Provider 会修改交易执行绑定。仅当策略引擎已明确处于 `stopped` 状态且任务与运行时资源已释放时才允许切换；`running`、`retrying`、`halted`、`recovery_required` 或状态不确定时均拒绝切换。切换失败会回滚数据库和运行时状态。

新增真实交易所适配时，必须分别实现并验证行情、账户、订单幂等、错误分类、限流、网络隔离和测试环境，不得把 Binance 网关作为兼容实现复用。
